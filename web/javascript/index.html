JavaScript教程

本教程主要参考Google 开发者网站文章和mdn文章，经过翻译整理

JavaScript 负责网页的“互动层”，作为标记提供的“结构”层和由 CSS 提供的“表示性”层的补充。JavaScript 允许开发者通过添加、移除和更改标记和样式来修改网页的结构和呈现方式，以响应用户互动和内部逻辑的任意组合。JavaScript 可让您对网页的呈现和行为进行很大程度的控制，甚至可以改变浏览器的某些内置行为。

本课程将介绍 JavaScript 的基础知识，包括控制语言如何写入其提供的内置方法和属性的基本规则。
